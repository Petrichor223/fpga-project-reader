# 时钟、复位与跨域

详细模式默认生成时钟树；快速模式在用户要求时钟树或时钟分配图时生成。阅读 [clock-tree.md](clock-tree.md)，使用统一时钟模型、可用的厂商查询或静态证据和离线绘图脚本。

## 从边沿和原语反向追踪

先找有效文件中的边沿敏感过程（包括 VHDL `rising_edge/falling_edge`）、双口 RAM/FIFO 时钟端口、DDR/SERDES/收发器和厂商时钟原语，再沿连接追溯到外部端口、PLL/MMCM、分频器、MUX/门控或恢复时钟。`clk` 命名搜索只用于候选发现；`tick` 等名称也可能真作时钟，`clk_enable` 也可能只是数据使能。

同一个源经层级端口、别名或普通时钟 buffer 分发时保留统一来源，另外记录路径。PLL 的相关输出属于不同运行时钟域，但不能因此直接断言互相异步。多边沿、可选源和动态频率需要分别标注。

## 时钟台账

每个时钟记录：

`时钟 ID | 配置 ID | 信号/实例路径及别名 | 产生方式/源 ID | 有效边沿 | 频率与性质 | 派生公式/模式 | 扇出模块 | 约束与例外 | 状态 | 证据`

频率性质必须说明是：外部规格、IP 配置推导、约束目标、仿真激励、工具识别还是实测。必要时同一时钟多列记录不同性质，不能强行合并成一个数值。

- **外部输入**：RTL 只能证明连接位置。板卡说明、原理图或器件配置可说明标称频率；缺失时频率未知。XDC 中周期不能单独证明晶振实物频率。
- **PLL/MMCM/IP**：核对当前实例绑定的配置、输入源和单位、反馈及输出分频、bypass/模式、动态重配置和输出连接。输入未知时可保留比例关系；配置输入频率与外部来源冲突时报告双方。
- **可复算推导**：只有已知原语公式和有效参数时计算；简单情况可写 `Fout = Fin × M / (D × O)`，但不得将此套用于所有厂商/原语。实现语言里的计数器终值也不总等于分频比，应核对翻转/脉冲及复位/使能行为。
- **MUX/门控/使能**：记录选择条件、候选源及 exclusive/模式约束。clock enable 不是新时钟；组合门控不可描述成已证实无毛刺。
- **恢复/收发器时钟**：线路速率不能直接当作用户时钟，须结合 PLL、并行宽度、协议编码和实际 IP 配置。
- **仿真时钟**：根据延迟、翻转和有效 `timescale`/`timeunit` 计算；标明激励而非板上工作频率。外部库/编译参数改变时间精度时保留条件。

所有频率/周期带单位。约束中周期若使用默认单位，核对工具或报告单位。缺少充分来源就填“未知”，可同时列已知范围/表达式和所需材料。

## 约束与工具结果

读取所选文件集的约束及递归 Tcl：primary/generated clocks、auto-derived clocks、virtual clocks、clock groups、false paths、multicycle、I/O delays、clock uncertainty，以及 IP 自带约束的作用域和处理顺序。虚拟时钟可用于 I/O 约束，不应分配虚构的内部驱动模块。

如工具可用，使用匹配版本的时钟清单、clock interaction、timing checks、CDC 以及异常约束报告校核；记录时序阶段和配置。只有文件中的 `create_clock` 文本而未解析选择对象，不能认定该约束已作用于有效对象。

区分：RTL 使用但未发现约束的时钟、仅约束中存在的时钟、工具自动推导的时钟、无法求值的约束及矛盾频率。工具对路径停止分析并不等于跨域安全。

## 跨域连接台账

每个重要跨域路径记录：

`源实例/寄存器 | 源时钟 ID | 目的实例/寄存器 | 目的时钟 ID | 信号/总线宽度 | 所见结构 | 约束关系 | 证据 | 未验证事项`

观察两级/多级同步、脉冲/切换同步、握手、异步 FIFO、Gray 指针、准静态配置和多位 coherency。要查看驱动端、接收端与同步中间级，模块名或 `ASYNC_REG` 属性只能作为线索。信号两侧结构未知则标“跨域候选”，不虚构安全结论。

对多位总线、脉冲持续时间、重汇聚和 Gray 指针物理约束，说明已看到什么及缺少什么。阅读任务不强制执行正式 CDC signoff；没有相应验证时写“结构观察，未作完整 CDC 验证”。

## 复位台账

记录每个复位的来源、极性、同步/异步断言与释放、覆盖时钟域、同步器、PLL lock/上电/软件复位依赖及复位顺序。将 HDL 敏感表证实的异步复位与“异步断言、同步释放”的完整路径分开判断。

跨域复位、未复位寄存器、不同复位顺序和 lock 未稳定即释放的可见路径附来源。未复位数据可能由 valid 限定，不能自动认定为 bug。无复位或依赖器件上电初值时按实际实现说明。
